# Put your brochure PDFs here

This folder is intentionally empty except for this guide.

1. Copy a PDF into this folder, for example `numbers-in-nature.pdf`.
2. Open `script.js`.
3. Find that brochure in the `brochureClasses` list.
4. Change its empty `pdf` value from `""` to:

   `"assets/pdfs/numbers-in-nature.pdf"`

The card's disabled **Add your PDF** label will automatically become a working
**Open brochure PDF** link. Repeat for the remaining brochures.
