# Brochure cover images

These 12 SVG files are obvious sample placeholders. Replace any file with your
own image while keeping the same filename, or update the matching `image` path
in the `brochureClasses` list near the top of `script.js`.

Recommended cover image format:

- JPG, PNG, WebP, or SVG
- Portrait artwork around a 3:4 aspect ratio
- At least 900 px wide for crisp desktop display
- Keep important text near the center because gallery cards crop the portrait
  cover into a landscape preview

Do not delete this folder unless every image path in `script.js` has been
updated to point somewhere else.
